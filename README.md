# Ship By Thursday

**Build a company from scratch in 72 hours, using Claude as the team.**

Tuesday Sept 15 → Thursday Sept 17, 2026. One human, one AI, one public repo.

---

## The premise

xAI is running [Grok Bot Galaxy](https://x.ai/galaxy) Sept 15–17: three SpaceXAI
staffers take a product from blank whiteboard to deployed, live on stream, with
Grok agents doing the work across engineering, product, sales, and support.

This is the same challenge, same clock, different model. Everything here is built
with [Claude](https://claude.com/claude-code) — the ideation, the code, the copy,
the go-to-market. Every commit is public. Every decision is logged, including the
wrong ones.

The point isn't to win a race. It's to have an honest, inspectable record of what
an AI-as-teammate build actually looks like over three days — what it's genuinely
good at, and where a human still has to step in.

## The rules

1. **Nothing pre-built.** The repo started empty on Sept 15. Check the git log.
2. **Claude does the labor.** Ideation, architecture, code, tests, copy, deploy.
   The human sets direction, makes judgment calls, and ships.
3. **Ship by Thursday.** Deployed and publicly usable by end of Sept 17, or it
   didn't happen.
4. **Log the misses.** Dead ends and rewrites go in the build log too. A record
   that only shows the wins isn't worth reading.
